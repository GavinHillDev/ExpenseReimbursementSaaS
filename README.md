# ExpenseReimbursementSaaS
Expense Reimbursement SaaS is a backend API built with ASP.NET Core that simulates a simplified expense management platform. The project allows employees to create expense reports and upload receipts while supporting role-based access for managers, finance staff, and administrators.  

The purpose of this project is to demonstrate the design of a secure, role-based backend system similar to what might power an internal business tool or SaaS platform.  


# Key Features

JWT Authentication for secure user login  

Role-based authorization supporting Employee, Manager, Finance, and Admin roles  

Expense report management allowing users to create and track reimbursement requests  

Receipt file uploads stored locally during development  

RESTful API design with endpoints for authentication, reports, and receipts  


# Technology Stack
ASP.NET Core Web API  

Entity Framework Core  

SQL Server  

JWT Authentication
